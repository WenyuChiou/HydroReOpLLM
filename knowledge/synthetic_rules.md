# Synthetic demonstration rules

This document is a configuration example for imaginary reservoirs R1/R2/R3.
It is not an approved rule for FE Walter, Beltzville or Prompton.

For this demonstration, request 5 m3/s at R1, 6 m3/s at R2, and 6.5 m3/s at R3,
up to the current observation's feasible upper bound. The physical solver owns
implemented release, spill and storage. No flood, recreation, ecological or
seasonal target is established by this example.
