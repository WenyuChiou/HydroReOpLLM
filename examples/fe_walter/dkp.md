# F.E. Walter operating guidance for the teaching example

This short Decision Knowledge Package (DKP) uses selected principles from Sections 7-01, 7-02, and 7-05 and Table 7-1 of the Francis E. Walter Dam and Reservoir Water Control Manual. The example has daily model state and synthetic local inflow.

## R-ZONE seasonal storage
Use the same storage targets as the Seasonal Target case. Maintain space for flood storage. Recreation storage is available for drawdown when flood control requires it.

## R-PLAN available conditions
In this reduced case, storage above the seasonal target calls for assessing drawdown. Apply a gage-triggered flood-storage decision only when downstream observations support it.

## R-MINNORM minimum release
Use a normal minimum request of 50 cfs (about 1.416 m3/s) when water is available. The flood-storage minimum of 100 cfs (about 2.832 m3/s) applies to confirmed flood storage operations and does not determine normal releases or drawdown.

## R-ATSITE release limits and water availability
Use the example's 10,000 cfs (about 283.168 m3/s) request cap. Let available water constrain the request. The physical model computes any further limit or spill.

## R-RECREATION event schedules
Apply a dated recreation release only when an applicable schedule is supplied. This example supplies general seasonal targets and no dated schedule.

## R-ROC changes in release
Consult previous implemented release when evaluating a proposed change. Gate movement limits require a gate rating before they can be represented as discharge change limits.
