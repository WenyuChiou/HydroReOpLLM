# Multiple-reservoir teaching snapshot

These selected files support the advanced notebook: the network setup, 31-day
trajectory, conservation summary, recorded causality comparison and overview figure.
They come from the previously completed January 2016 experiment; no simulation was rerun.

The complete research run and its raw journals are retained separately.
The historical acceptance receipt describes that original run. This selection
does not include all files named in that receipt and is not a complete restart bundle.

Use [the advanced tutorial](../../../../tutorials/advanced.ipynb) to inspect the
configuration and saved results. Create new outputs under `runs/`.
