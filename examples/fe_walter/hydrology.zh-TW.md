# FE Walter：水文、參數與校正／驗證

[English](hydrology.md) | [繁體中文](hydrology.zh-TW.md) · [案例](README.zh-TW.md)

本頁解釋**本案例**如何產生入流，再接上水庫操作。列出的資料、參數及 C&V 都沿用已接受的成果；整理手冊未重跑水文或校正。

## 1. 從氣象到壩址入流

**各區氣象 → HydroCNHS GWLF → Lohmann 上游 routing → 壩址匯總入流。**

七個真實子集水區保留不同的氣象、面積、緯度、土壤／土地特徵與河長。原生 YAML 還有一個 1 ha 的計算匯總節點；重現入口對它指定零產流，它不是第八個實際集水區。

操作實驗讀取凍結的每日入流。LLM 只提出放流；共同物理計算更新蓄水並計算 spill，下游 routing 再接收實際總出流。它不改寫 GWLF 或回頭修改上游氣象。上游已校正的 Lohmann 與三日操作教學的下游 `UH=[1.0]` 是不同設定；後者只是透明的介面示範。

## 2. 資料與期間

| 輸入 | 本案例使用方式 |
|---|---|
| 氣象 | Daymet V4 R1 每日降雨及最低／最高溫，依多邊形面積加權。NOAA nClimGrid-Daily 只補記錄中的閏年 12 月 31 日，不作一般缺值補齊。 |
| 模型輸入單位 | 溫度 °C；降雨與 PET 為 cm/day。Forcing 檔降雨為 mm/day，進入 GWLF 前換算。PET 沿用給定序列；保留的來源 manifest 沒有另外說明推估方法。 |
| 流量觀測 | USGS 01447500 每日流量用於 C&V，只涵蓋七區中的兩區；其餘五區沒有各自的測站驗證。 |
| 土地與土壤 | Annual NLCD 2021 與 NRCS Soil Data Access 圖斑／屬性。水文土壤組及上部 100 cm 可用水量用於 CN2 與 Ur；不是下載的 gSSURGO raster。 |
| 幾何 | 地圖取得的子集水區面積、緯度與河道路徑長度；原生 FlowLength 使用 m。 |
| 期間 | Warm-up：1989；校正：1990–2010；驗證：2011–2020；凍結參數後延伸：2021–2025。原生連續執行 1989–2025；水庫參考入流交付 1996–2025。 |

## 4. 共用的 GWLF 與 routing 參數

原成果用 HydroCNHS `GA_DEAP` 聯合選定 **13 個搜尋值**：兩個對地圖 CN2／Ur 的共同調整值、七個共用 GWLF 值及四個共用 Lohmann 值。這不表示每個未設站單元都各自校正九個參數；下表是最終共用參數，前表是已調整後的各區 CN2／Ur。

| 參數 | 作用 | 單位 | 保存值 |
|---|---|---|---:|

| `Sep` | 深層滲漏係數 | day⁻¹ | 0.2083763352 |
| `Alpha` | 基流分配係數 | — | 0.008265514706 |

## 5. 已接受的校正與驗證結果

| 指標 | 校正 1990–2010 | 驗證 2011–2020 |
|---|---:|---:|
| KGE (2009) | 0.7326 | 0.7112 |
| NSE | 0.4428 | 0.4576 |
| RMSE (m³/s) | 5.6774 | 4.6012 |
| PBIAS (%) | 0.0943 | 1.4072 |
| 平均洪峰時間誤差（日） | 2.4000 | 4.4000 |
| 平均相對洪峰流量誤差 (%) | 44.6945 | 57.1134 |
| 誤報／漏報 | 4 / 4 | 7 / 7 |
| 有效每日觀測數 | 7670 | 3653 |

PBIAS 正值代表高估。PFE 的 CSV 原值為 fraction，這裡乘 100 顯示百分比。洪峰指標是事件平均，保留未配對事件的既定 penalty；每期選取 15 個觀測事件，間隔至少七日，在 ±7 日內一對一配對。門檻只取自校正觀測。這是測站尺度水文評估，不代表五個未設站區各自通過驗證，也不代表 LLM 策略已通過。

### 固定參數重現

2026 年 10 月 16 日的重現沿用 commit `8d59dcac2f9d06fe16030f68826b425d492c9529`
的準備與評估程式，以及保存的最佳參數。從保留的物理屬性表重建七區的 CN2、Ur
與共用參數後，每個值都與已接受的原生 YAML 一致。

測站 01447500 只使用 FEW-D-01/02 及其測站 routing 河長 5,856 m、1 m，
沒有改用通往水庫的較長河道。校正觀測的 Q95 為 15.630899318784 m³/s，
驗證期沿用同一門檻。28 項純量指標均在絕對誤差 1e-9、相對誤差 1e-10 內重現。

| 核對項目 | 重現結果 |
|---|---|
| 公開 HydroCNHS Model 與原生 kernel 的測站計算 | 最大差異 3.02 × 10⁻¹⁴ m³/s |
| 七區 1989–2025 連續水文 | 13,514 個模擬日 |
| 1996–2025 水庫入流與保留參考序列 | 10,958 日；最大差異 1.09 × 10⁻¹¹ cfs |
| 獨立水庫入流 routing 卷積 | 最大差異 1.14 × 10⁻¹³ m³/s |

[重現指標](../../docs/results/fe_walter/hydrology/reproduced_cv_metrics_20261016.csv)與
[重現紀錄](../../docs/results/fe_walter/hydrology/reproduction_20261016.json)保存數值、runtime、
來源雜湊及容許誤差；原始逐日輸出與恢復的研究程式保留在外部證據包。
這次歷史重現從保留的邊界屬性表與 forcing 開始，未重做幾何劃分或土地／土壤疊合，
也未執行 optimizer、模型請求或模擬網路存取。它驗證可重現性，並非新校正或 LLM 策略驗收。
