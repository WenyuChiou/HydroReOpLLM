# 模型決策時能看到什麼

從單一步驟檢查資訊。決策發生在期初，操作器能用哪些資料，由實驗設定與該時點可取得的輸入決定。期末庫容是執行放流後算出的結果。

## 從範例找輸入

打開[雙水庫範例](../examples/multiple_reservoirs/README.md)的 LLM 設定，依它引用的檔案找到操作器、模型與 prompt。將作業規則或操作知識放入案例時，要一併保存文件版本、單位和適用水庫。比較季節目標和操作知識的效果時，也要保留實際送出的文字與模型回覆。

## 從輸出核對決策

結果表記錄放流與庫容；要回答「這一步送了什麼給模型」，另看該次執行保存的決策紀錄，依水庫與時間對回結果表。使用指定放流的離線案例可以驗證流程；它沒有實際模型回覆。完整的輸入欄位與時序見[決策資訊章](INFORMATION.md)。
