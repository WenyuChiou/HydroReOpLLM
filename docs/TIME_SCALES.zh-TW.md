# 時間尺度與單位

公開範本與 F.E. Walter 案例採用目前持續維護的逐日工作流程。個別研究亦可使用系統支援的逐時或固定時距設定，但驅動資料、演算與水庫時鐘必須一致。

| 物理量 | 單位或慣例 |
|---|---|
| 蓄水量、庫容 | m3 |
| 放流量、溢流量、入流量 | 時段平均 m3/s |
| `dt_seconds` | 每個操作時間步的秒數 |
| 演算權重 | 無因次，總和為 1 |
| 逐日降雨量／PET | 該日累積水深 |
| 逐時降雨量／PET | 該時段的累積水深 |
| 氣溫 | 時段平均值（°C） |

在恆定的時段平均流量下，體積變化量為 `flow * dt_seconds`。切勿將逐日驅動資料或逐日單位歷線時段誤標為逐時資料。使用較細尺度的驅動資料時，還必須搭配支援對應時距的逕流核心、連續的時間戳記、正確積分的水深、對應時距的演算設定，以及相容的水庫操作步長。

[實驗性逐時 GWLF 流程](HOURLY_GWLF.zh-TW.md)接受 3600、1800 或 900 秒的時間步長。這是一套工程化公式實作，並不代表已具備經率定驗證的逐時模擬能力。
