# 疑難排解

| 問題現象 | 檢查項目 |
|---|---|
| 找不到檔案 | 路徑皆相對於宣告該路徑的設定檔位置。 |
| 未知的水庫或節點 | 請確認大小寫、水文綁定與操作員 ID 完全一致。 |
| 輸出目錄已存在 | 請選擇新的 `run_id` 與尚未使用的輸出目錄。 |
| 水量重複計算 | 下游局部入流量不得包含上游已演算傳遞的放流量。 |
| 模型服務的身分驗證失敗 | 請設定 `api_key_env` 所指定的環境變數。 |
| 模型服務供應商選項遭拒 | 請對照[供應商控制項](LLM_MODULES.zh-TW.md)檢查設定檔。 |
| 逐時模擬結果異常 | 請重新檢查累積水深單位、時間戳記、演算設定與初始狀態。 |
| 執行中斷 | 請保留部分輸出成果，並依[接續執行](RUNNING.zh-TW.md#resume-an-interrupted-operation)步驟處理。 |
| 耦合輸出缺少 `summary.json` | 請至 `<output>/operation/` 底下查閱。僅含前處理的目錄不會有已完成的操作成果。 |
| 資訊欄位無法取得 | 請檢查 `available_at`、`valid_time`/`issued_at`、`max_age_seconds`、設定檔綁定與 `required`。 |

修正設定後，請重新執行 `reservoir-experiment check CONFIG`。若診斷時需要參考失敗紀錄，請妥善保留失敗的輸出內容。單憑模型服務供應商的回覆，並不足以證明系統已完整寫入決策紀錄。

調整輸入資料前，請先透過[結果指南](RESULTS_GUIDE.zh-TW.md)定位追蹤、稽核與水量平衡證據。
