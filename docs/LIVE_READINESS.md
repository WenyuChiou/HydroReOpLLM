# Before a real LLM experiment

The tutorial reads saved three-day local Ollama results by default. The two
model configurations retain temperature **0.7**, original prompts, retrieval and
audit; `check` never calls a provider. Only the separate bounded demo case is
ready for its stated diagnostic assumptions. Broader experiments need the
conditions below.

| Condition | Current status / required action |
|---|---|
| Starting storage and pool level | FE reference starts at 1,992.61 acre-ft (2,457,848.279729185 m³), an assumed V3.7 condition. Confirm a dated observation or justify it as an experiment assumption. |
| Physical capacity and public facts | Physical capacity is 109,878 acre-ft; the preserved prompt states 110,700. Document and approve that original discrepancy for a reproduction, or version a revised profile/prompt. |
| Downstream routing | Identity UH tests connectivity only. Supply and verify appropriate routing parameters/delay and initial channel state for the actual site. |
| Operating policy | Original seasonal target is simplified. Resolve year/date-specific schedules, DKP 2014 exhibit applicability, environmental-flow exceptions and required missing inputs; do not transfer FE rules to another reservoir. |
| Other reservoirs | Own geometry, storage/elevation and outlet curves, initial state, prompt/knowledge, versioned auditors; passive Prompton needs no LLM and its strategy status remains UNKNOWN. |
| Model and provider | Explicit installed/available model ID, supported structured output/temperature, timeout/token limits, credential environment variable name, and approved request budget; no automatic downloads. |
| Scientific comparison | Same forcing/initial state/physics/routing across the rule benchmark and both named LLM information designs; defined performance metrics, stochastic replications and failure handling before interpretation. |
| Readiness gate | Create a new case with supported values and explicit live readiness; use new run/output IDs. No accepted scientific input is overwritten. |

Malformed, truncated or transport-failed replies stop before release. No automatic
fallback, retry, silent temperature change or policy PASS promotion occurs.
The existing 2016–2020 diagnostic trajectory and failed/unknown attempts remain
historical evidence; their audit FAIL does not establish an accepted policy.
